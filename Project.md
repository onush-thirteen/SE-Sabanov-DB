# Финансовый центр — личный финансовый менеджер

Одностраничное веб-приложение (SPA) для управления личными финансами. Все данные вводятся вручную и сохраняются локально в браузере (`localStorage`) — без интеграции с банками и без сервера/базы данных.

**Демо:** https://onush-thirteen.github.io/SE-Sabanov-DB/

## Функциональные модули

1. **Обзор** — общий баланс по всем счетам, последние операции, динамика чистого капитала
2. **Доходы и расходы** — учёт операций по категориям, фильтры, история, разбивка расходов по категориям
3. **Кредиты** — сумма, ставка, срок, ежемесячный платёж (аннуитет), график погашения, остаток долга
4. **Депозиты** — сумма, ставка, срок, капитализация, доход на текущую дату
5. **Накопления** — копилки с целевой суммой и прогресс-баром
6. **Крупные покупки** — планирование по сумме, сроку и источнику средств
7. **Финансовые цели** — цель, сумма, срок, текущий прогресс, приоритет
8. **Бюджет** — план по категориям доходов/расходов на месяц
9. **План-факт** — сравнение плана и факта по категориям с отклонениями, помесячная навигация
10. **Прогноз остатка денег** — на основе среднего дохода/расхода и графика платежей по кредитам
11. **Чистый капитал** — активы (счета, депозиты, накопления, имущество) минус обязательства (кредиты), динамика во времени
12. **Долговая нагрузка** — % платежей по кредитам от дохода, индикатор риска (норма / повышенная / критическая)
13. **AI-рекомендации** — советы на основе введённых данных (свободные средства, риски, перерасход, темп накоплений)
14. **Годовой финансовый план** — помесячная раскладка бюджета, целей и кредитных платежей на 12 месяцев вперёд

## Технологии

- Чистый HTML/CSS/JavaScript (без фреймворков и сборки)
- Хранение данных: `localStorage` браузера
- Шрифты: Manrope, Public Sans, IBM Plex Mono (Google Fonts)
- Графики и индикаторы — собственная реализация на inline SVG (без внешних библиотек)
- Поддержка светлой/тёмной темы, адаптивная вёрстка (десктоп/мобильный)
- Валюта по умолчанию — тенге (₸), с возможностью смены (₸ / $ / € / ₽ / ₴)

## Структура репозитория

```
index.html   — вся логика и разметка приложения (единый файл)
Project.md   — описание проекта
```

## Запуск локально

Файл `index.html` не требует сборки или сервера — достаточно открыть его в браузере.

## Данные

При первом запуске приложение показывает демонстрационные данные (баннер с кнопкой «Очистить всё» позволяет начать с чистого листа). Все дальнейшие изменения сохраняются в браузере пользователя и не передаются на сервер.
